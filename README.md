# Чат MAX через GREEN-API

Веб-приложение (React + TypeScript + Vite) для отправки и получения **текстовых** сообщений в мессенджере **MAX**
через сервис [GREEN-API](https://green-api.com/max).

Тестовое задание на должность «Фронтенд разработчик React».

> Пошаговая инструкция по локальному запуску — в файле [`RUN.md`](RUN.md).

## Возможности

- Вход по учётным данным инстанса GREEN-API (`apiUrl`, `idInstance`, `apiTokenInstance`).
- Создание чата по номеру телефона получателя (с проверкой наличия аккаунта в MAX).
- Отправка и приём текстовых сообщений, лента диалога.
- Индикатор состояния инстанса (`authorized` / `notAuthorized` и т.д.).
- Учётные данные сохраняются только в браузере (`localStorage`).

## Требования

- Node.js 20+ (проверено на Node.js 24).
- npm.
- Аккаунт и инстанс GREEN-API: `console.green-api.com` (тариф **MAX Developer**, 0 ₽).
- Инстанс, авторизованный в MAX (иначе сообщения не доставляются).

## Как пользоваться

1. Откройте приложение — появится форма входа.
2. Введите данные инстанса из личного кабинета GREEN-API:
   - **apiUrl** — адрес API вашего инстанса (например `https://3100.api.green-api.com`),
   - **idInstance**,
   - **apiTokenInstance**.
3. Введите номер телефона получателя (РФ — `79991234567`, РБ — `375291234567`) и нажмите «Создать чат».
   Приложение через `checkAccount` получит внутренний `chatId` получателя.
4. Напишите сообщение и отправьте. Ответ получателя из MAX появится в ленте (проверка уведомлений — каждые 5 секунд).

### Что нужно для доставки сообщений

- Инстанс должен быть **авторизован в MAX**: приложение MAX → `Профиль → Устройства → Войти по QR-коду`,
  затем в кабинете GREEN-API «Получить QR-код для авторизации» (пароль входа в MAX должен быть отключён).
- Получатель должен быть зарегистрирован в MAX.
- Для проверки приёма ответа нужен второй аккаунт MAX.

> Если инстанс не авторизован, `sendMessage` всё равно вернёт `idMessage`, а сообщение попадёт в очередь
> (до 24 часов) и уйдёт только после авторизации. Ориентируйтесь на индикатор состояния в шапке.

## Используемые методы GREEN-API

- `sendMessage` — отправка текста: https://green-api.com/v3/docs/api/sending/SendMessage/
- `receiveNotification` / `deleteNotification` — приём (HTTP API): https://green-api.com/v3/docs/api/receiving/technology-http-api/
- `checkAccount` — получение `chatId` по номеру: https://green-api.com/v3/docs/api/service/CheckAccount/
- `getStateInstance` — состояние инстанса: https://green-api.com/v3/docs/api/account/GetStateInstance/

## Структура проекта

```
  components/LoginForm.tsx    — экран ввода учётных данных

  components/MessageInput.tsx — поле ввода и отправки

  types.ts                    — типы API и сообщений

```
